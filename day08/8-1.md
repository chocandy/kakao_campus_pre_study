# HTML 기초

## 웹(Web)이란?

### 웹의 개념
- Web은 World Wide Web의 약자
- 인터넷을 통해 서로 연결된 문서와 정보의 집합
- 서버(Server)가 정보를 제공하고 클라이언트(Client)가 이를 받아 화면에 표시

### 웹의 동작 구조

```text
서버(Server)
    ↓
HTML + CSS + JavaScript
    ↓
클라이언트(Client)
```

### 웹 페이지 구성 요소

| 기술 | 역할 |
|--------|--------|
| HTML | 웹 페이지의 구조와 내용 |
| CSS | 웹 페이지의 디자인과 스타일 |
| JavaScript | 웹 페이지의 동적인 기능 |

### 비유

- HTML : 뼈대(Skeleton)
- CSS : 피부(Skin)
- JavaScript : 두뇌(Brain)

---

## HTML 소개

### HTML

- HyperText Markup Language의 약자
- 웹 페이지를 구성하기 위한 마크업 언어
- 웹 문서의 구조와 내용을 정의
- 태그(Tag)를 이용하여 텍스트, 이미지, 링크 등을 구성

### HyperText
- 링크를 통해 다른 문서나 웹 페이지로 이동할 수 있는 기능

### Markup
- 태그를 사용하여 문서 각 부분의 의미를 표현하는 것

---

## HTML 기본 문법

### 태그(Tag)

```html
<태그이름 속성="속성값">
    콘텐츠
</태그이름>
```

### 구성 요소

- 태그이름 : 요소의 종류를 나타냄
- 콘텐츠 : 실제 화면에 표시될 내용
- 속성 : 태그에 기능 추가
- 속성값 : 속성의 설정 값

### 태그 규칙

```html
<p>문단</p>
```

- 여는 태그와 닫는 태그 이름이 동일해야 함
- 닫는 태그에는 `/` 사용

---

## Self-closing Tag

### 특징
- 콘텐츠가 없는 태그
- 별도의 닫는 태그가 필요 없음

### 예시

```html
<br />
<img />
<input />
```

### 용도

- br : 줄바꿈
- img : 이미지 삽입
- input : 입력창 생성

## HTML 문서 기본 구조

```html
<!DOCTYPE html>
<html>
<head>
    <title>페이지 제목</title>
</head>
<body>

</body>
</html>
```

### 주요 태그

#### DOCTYPE

```html
<!DOCTYPE html>
```

- HTML5 문서임을 선언

#### html

```html
<html></html>
```

- HTML 문서의 시작과 끝

#### head

```html
<head></head>
```

- 메타데이터 저장
- CSS, JavaScript 연결

#### title

```html
<title>제목</title>
```

- 브라우저 탭에 표시되는 제목

#### body

```html
<body></body>
```

- 실제 화면에 표시되는 내용 작성

## 컨테이너 태그

### div

```html
<div>내용</div>
```

- Block 요소
- 항상 새로운 줄에서 시작
- 부모 영역 전체 너비 사용

### span

```html
<span>내용</span>
```

- Inline 요소
- 줄바꿈 없이 텍스트 일부를 묶음

### 차이점

| 태그 | 특징 |
|--------|--------|
| div | Block 요소 |
| span | Inline 요소 |

## class와 id

### 공통점

- HTML 요소를 식별하기 위한 속성
- CSS와 JavaScript에서 선택자로 사용

---

## class

### 특징

- 여러 요소가 같은 class 사용 가능
- 한 요소에 여러 class 지정 가능

```html
<div class="main"></div>

<div class="main important"></div>
```

### 활용 목적

- 같은 스타일을 여러 요소에 적용
- 요소 그룹화

---

## id

### 특징

- 문서 내에서 유일해야 함
- 한 요소당 하나만 사용

```html
<div id="header"></div>
```

### 활용 목적

- 특정 요소 하나를 식별

### 규칙

- 공백 사용 불가
- 특수문자 사용 불가
- 대소문자 구분
- 숫자만으로 구성 불가

---

## class와 id 비교

| class | id |
|---------|---------|
| 중복 사용 가능 | 중복 사용 불가 |
| 여러 개 지정 가능 | 하나만 지정 가능 |
| 그룹 선택 | 특정 요소 선택 |

## 이미지 요소

### img

```html
<img src="logo.png" alt="엘리스 로고" />
```

### 주요 속성

| 속성 | 역할 |
|--------|--------|
| src | 이미지 경로 |
| alt | 대체 텍스트 |

### alt의 역할

- 이미지가 로드되지 않을 때 표시
- 스크린 리더 지원
- 웹 접근성 향상

---

## 링크 요소

### a

```html
<a href="https://elice.io">
    엘리스 홈페이지
</a>
```

### 주요 속성

| 속성 | 역할 |
|--------|--------|
| href | 이동할 주소 |
| target | 링크 열기 방식 |

### target

```html
target="_self"
```

- 현재 탭에서 이동

```html
target="_blank"
```

- 새 탭에서 이동

## 폼(Form)

### form

```html
<form>
</form>
```

- 사용자 입력을 서버로 전달하는 영역

### 주요 속성

| 속성 | 역할 |
|--------|--------|
| method | 전송 방식 |
| action | 전송 주소 |
| name | 폼 이름 |

### 전송 방식

#### GET

- 주소창에 데이터 노출

#### POST

- 요청 본문으로 전송
- 주소창에 표시되지 않음

---

## 입력 요소

### label

```html
<label for="name">이름</label>
```

- 입력 요소 설명

### input

```html
<input type="text">
```

- 한 줄 입력

### textarea

```html
<textarea></textarea>
```

- 여러 줄 입력

## input 타입

| 타입 | 설명 |
|--------|--------|
| text | 일반 텍스트 |
| email | 이메일 |
| url | URL |
| password | 비밀번호 |
| radio | 단일 선택 |
| checkbox | 다중 선택 |


| 속성 | 역할 |
|--------|--------|
| placeholder | 입력 힌트 |
| name | 서버 전송 키 |

## Semantic HTML5

### Semantic 태그

- 태그 이름만 보고 역할을 이해할 수 있는 태그
- div보다 의미가 명확함

### 장점

- 가독성 향상
- 유지보수 용이
- 웹 접근성 향상
- SEO(검색 엔진 최적화) 지원

---

## 주요 Semantic 태그

| 태그 | 역할 |
|--------|--------|
| header | 머리글 |
| nav | 메뉴 |
| main | 주요 콘텐츠 |
| article | 독립 콘텐츠 |
| aside | 사이드바 |
| footer | 바닥글 |

### 예시

```html
<header></header>

<nav></nav>

<main>
    <article></article>
</main>

<aside></aside>

<footer></footer>
```

## 핵심 정리

- HTML은 웹 페이지의 구조와 내용을 정의하는 마크업 언어이다.
- HTML, CSS, JavaScript가 함께 웹 페이지를 구성한다.
- HTML은 태그를 사용하여 문서를 구조화한다.
- h, p, ul, ol 등을 이용해 텍스트를 표현한다.
- div는 Block 요소, span은 Inline 요소이다.
- class는 여러 요소를 그룹화할 때 사용한다.
- id는 특정 요소를 고유하게 식별할 때 사용한다.
- img는 이미지를, a는 링크를 생성한다.
- table은 표 데이터를 표현한다.
- form은 사용자 입력을 처리한다.
- Semantic 태그는 의미 있는 구조를 제공하고 SEO와 접근성을 향상시킨다.
