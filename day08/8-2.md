# CSS 기초

## CSS 소개

### CSS란?

- Cascading Style Sheets의 약자
- 웹 페이지의 스타일과 레이아웃을 지정하는 언어
- HTML이 구조를 담당한다면 CSS는 디자인을 담당

### CSS의 역할

- 색상, 글꼴, 크기 지정
- 레이아웃 구성
- 디자인 일관성 유지
- 유지보수성 향상
- 웹 접근성 향상

### CSS 의미

#### Cascading

- 스타일이 위에서 아래로 적용되는 구조
- 상위 요소의 스타일이 하위 요소로 상속될 수 있음
- 여러 스타일 규칙이 충돌하면 우선순위에 따라 적용

---

## CSS 기본 문법

### 기본 구조

```css
선택자 {
    속성: 값;
}
```

### 예시

```css
p {
    color: blue;
    font-size: 16px;
}
```

### 구성 요소

| 구성요소 | 설명 |
|-----------|-----------|
| 선택자(Selector) | 스타일 적용 대상 |
| 속성(Property) | 변경할 스타일 종류 |
| 값(Value) | 속성에 적용할 값 |
| 선언(Declaration) | 속성과 값의 조합 |

---

## CSS 적용 방법

### 외부 스타일 시트

```html
<link rel="stylesheet" href="style.css">
```

```css
body {
    background-color: yellow;
}
```

#### 특징

- 가장 권장되는 방식
- 재사용성 높음
- 유지보수 편리

---

### 내부 스타일 시트

```html
<head>
    <style>
        p {
            color: blue;
        }
    </style>
</head>
```

#### 특징

- 해당 HTML 문서에만 적용

---

### 인라인 스타일

```html
<p style="color:red; font-size:18px;">
    내용
</p>
```

#### 특징

- 특정 요소에 직접 적용
- 유지보수가 어려워 권장되지 않음

---

## 스타일 우선순위

### 적용 순서

```text
1. 인라인 스타일
2. 내부 스타일 시트
3. 외부 스타일 시트
4. 브라우저 기본 스타일
```

### 규칙

- 인라인 스타일이 가장 우선
- 내부/외부 스타일은 나중에 작성된 규칙이 우선

# 기본 선택자

## 전체 선택자

### 문법

```css

    margin: 0;
    padding: 0;
}
```

### 특징

- 모든 HTML 요소 선택
- reset CSS 작성 시 자주 사용

---

## 태그 선택자

### 문법

```css

    font-size: 16px;
```

### 특징

---

## 클래스 선택자

- 가장 많이 사용하는 선택자

# CSS 우선순위

### 높은 순서

```text
!important
↓
인라인 스타일
↓
ID 선택자
↓
클래스 선택자
↓
태그 선택자
↓
전체 선택자
```

### 규칙

- 우선순위가 높은 선택자가 적용
- 우선순위가 같으면 더 구체적인 선택자 적용
- 모두 같으면 나중에 작성된 스타일 적용

## Margin Collapsing

### 마진 상쇄

- 인접한 Block 요소의 상하 margin이 겹치는 현상
- 더 큰 margin 값만 적용됨

예)

```text

→ 80px 아님
→ 50px 적용
```

# 핵심 정리

- CSS는 웹 페이지의 디자인을 담당한다.
- 선택자를 이용해 HTML 요소를 선택한다.
- class는 여러 요소, id는 특정 요소를 선택할 때 사용한다.
- 가상 선택자를 이용해 상태 변화에 스타일을 적용할 수 있다.
- 박스 모델은 Content, Padding, Border, Margin으로 구성된다.
- Flex는 1차원 레이아웃, Grid는 2차원 레이아웃이다.
- Position을 이용해 요소의 위치를 자유롭게 조정할 수 있다.
- 외부 스타일 시트 사용이 가장 권장된다.
