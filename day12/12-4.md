# 비동기 처리의 원리

# 타이머 함수(Timer Functions)

## 타이머 함수란?

- JavaScript에서 함수 실행을 예약하기 위한 기능
- 일반 함수 호출과 달리 특정 시점에 실행되도록 설정 가능

주요 함수

- setTimeout()
- setInterval()

---

# setTimeout()

## setTimeout이란?

특정 시간이 지난 후 콜백 함수를 한 번 실행

기본 문법

```javascript
setTimeout(
    callback,
    delay
);
```

- callback : 실행할 함수
- delay : 대기 시간(ms)

---

## 사용 예시

```javascript
console.log("3초 후 메시지 출력");

setTimeout(() => {
    console.log("3초가 지났습니다.");
}, 3000);
```

실행 순서

```text
3초 후 메시지 출력
(3초 대기)
3초가 지났습니다.
```

---

## 콜백 함수 인수 전달

세 번째 이후 인수는 콜백 함수로 전달됨

```javascript
setTimeout(
    (name) => {
        console.log(
            `Hello, ${name}`
        );
    },
    2000,
    "Elice"
);
```

결과

```text
2초 후
Hello, Elice
```

---

# clearTimeout()

## clearTimeout이란?

예약된 setTimeout 제거

예시

```javascript
const timeoutId =
    setTimeout(() => {
        console.log("Hello");
    }, 2000);

clearTimeout(timeoutId);
```

특징

- setTimeout은 timeout id 반환
- clearTimeout(id)로 예약 취소 가능

---

# setInterval()

## setInterval이란?

일정 시간마다 반복 실행

기본 문법

```javascript
setInterval(
    callback,
    delay
);
```

---

## 사용 예시

```javascript
let count = 0;

setInterval(() => {

    count++;

    console.log(
        `${count}초 경과`
    );

}, 1000);
```

결과

```text
1초 경과
2초 경과
3초 경과
...
```

---

# clearInterval()

## clearInterval이란?

반복 실행 중지

예시

```javascript
let count = 0;

const intervalId =
    setInterval(() => {

        count++;

        console.log(count);

        if (count === 5) {
            clearInterval(intervalId);
        }

    }, 1000);
```

결과

```text
1
2
3
4
5
(종료)
```

특징

- setInterval은 interval id 반환
- clearInterval(id)로 반복 제거 가능

# 자바스크립트 엔진

## 자바스크립트 엔진이란?

- JavaScript 코드를 해석하고 실행하는 프로그램
- 브라우저마다 엔진이 존재

예시

- Chrome → V8 엔진
- Firefox → SpiderMonkey

특징

- 코드 파싱
- 코드 실행
- 메모리 관리

# 실행 컨텍스트(Execution Context)

## 실행 컨텍스트란?

코드 실행에 필요한 정보를 저장하는 환경

포함 정보

- 변수
- 함수 선언
- this 바인딩
- 스코프 정보

---

## 실행 컨텍스트 생성 과정

### 생성 단계

```javascript
let a;
function test() {}
```

변수와 함수 선언 저장

---

### 실행 단계

```javascript
a = 10;
```

실제 코드 실행

---

## 실행 컨텍스트 생성 시점

각 스코프가 실행되기 직전에 생성됨

예시

```javascript
const x = 10;

function func1() {
    const y = 20;

    func2();
}

function func2() {
    console.log(x);
}
```

생성 순서

```text
전역 실행 컨텍스트
↓
func1 실행 컨텍스트
↓
func2 실행 컨텍스트
```

---

# 실행 컨텍스트 스택(Call Stack)

## 콜 스택이란?

실행 중인 실행 컨텍스트를 저장하는 공간

특징

- Stack 구조
- LIFO(Last In First Out)
- 가장 나중에 들어온 작업이 먼저 종료

---

## 실행 예시

```javascript
function outer() {
    inner();
}

function inner() {
    console.log("hello");
}

outer();
```

콜 스택 변화

```text
전역 컨텍스트
```

↓

```text
outer
전역
```

↓

```text
inner
outer
전역
```

↓

```text
outer
전역
```

↓

```text
전역
```

# 싱글 스레드(Single Thread)

## JavaScript의 특징

JavaScript는 싱글 스레드 기반 언어

즉,

```text
한 번에 하나의 작업만 수행 가능
```

특징

- 작업 순서 보장
- 구조 단순
- 동시 실행 불가능

---

# 싱글 스레드의 문제점

## Blocking

앞선 작업이 끝날 때까지 다음 작업 수행 불가

예시

```javascript
readFileSync();
console.log("다음 작업");
```

동작

```text
파일 읽기 완료 대기
↓
다음 작업 실행
```

문제점

- 긴 작업이 있으면 전체 프로그램이 멈춘 것처럼 보임

---

# 동기(Synchronous)

## 동기 처리란?

현재 작업이 끝날 때까지 다음 작업이 기다리는 방식

예시

```javascript
task1();

task2();

task3();
```

실행 순서

```text
task1
↓
task2
↓
task3
```

특징

- 순서 보장
- 직관적
- Blocking 발생 가능

---

# 비동기(Asynchronous)

## 비동기 처리란?

작업 완료를 기다리지 않고 다음 작업을 실행

예시

```javascript
readFile(
    "file.txt",
    (err, data) => {
        console.log(data);
    }
);

console.log("다른 작업 실행");
```

실행 순서

```text
파일 읽기 시작
↓
다른 작업 실행
↓
파일 읽기 완료
↓
콜백 실행
```

특징

- Blocking 감소
- 효율적인 자원 활용
- 콜백, Promise, async/await 사용

# Event Loop

콜 스택과 태스크 큐를 감시

동작

```text

        ↓
      YES
        ↓
Task Queue 작업을
Call Stack으로 이동
```

# setTimeout 실행 예시

```javascript
console.log("1");

setTimeout(() => {
    console.log("3");
}, 0);

console.log("2");
```

실제 결과

```text
1
2
3
```

---

## 실행 과정

### 1단계

```javascript
console.log("1");
```

출력

```text
1
```

---

### 2단계

```javascript
setTimeout(...)
```

- 콜백 등록
- 즉시 실행되지 않음

---

### 3단계

```javascript
console.log("2");
```

출력

```text
2
```

---

### 4단계

콜 스택 비어짐

```text
Call Stack Empty
```

---

### 5단계

Event Loop가 Task Queue의 콜백을 콜 스택으로 이동

---

### 6단계

```javascript
console.log("3");
```

출력

```text
3
```

# 핵심 정리

- setTimeout()은 일정 시간 후 한 번 실행
- setInterval()은 일정 시간마다 반복 실행
- clearTimeout(), clearInterval()로 예약 제거 가능
- JavaScript 코드는 자바스크립트 엔진이 실행
- 실행 컨텍스트는 코드 실행에 필요한 정보를 저장
- 실행 컨텍스트는 콜 스택에서 관리됨
- JavaScript는 싱글 스레드 기반 언어
- 싱글 스레드는 한 번에 하나의 작업만 수행 가능
- 동기는 작업 완료 후 다음 작업 수행
- 비동기는 작업 완료를 기다리지 않고 다음 작업 수행
- 비동기는 Task Queue와 Event Loop를 이용해 동작
- Event Loop는 콜 스택이 비면 Task Queue의 작업을 실행
- setTimeout(..., 0)이라도 즉시 실행되지 않고 현재 작업 종료 후 실행됨
