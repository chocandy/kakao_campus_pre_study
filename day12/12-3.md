# JavaScript 내장 객체(Built-in Objects)

## 내장 객체란?

- JavaScript에서 기본적으로 제공하는 객체
- 숫자, 문자열, 날짜, JSON 데이터 등을 쉽게 다룰 수 있도록 다양한 기능 제공
- 별도의 라이브러리 설치 없이 바로 사용 가능

주요 내장 객체

- window
- document
- Number
- Math
- Date
- String
- JSON

---

# window 객체

## window란?

브라우저 창 자체를 나타내는 객체

특징

- 브라우저 환경의 전역 객체
- document 객체를 포함
- 창 정보 조회 가능
- 브라우저 창 제어 가능

예시

```javascript
console.log(window.innerWidth);
console.log(window.innerHeight);
```

새 창 열기

```javascript
window.open(
    "https://www.naver.com",
    "target"
);
```

활용

- 브라우저 크기 확인
- 새 창 열기
- 타이머 실행

---

# document 객체

## document란?

현재 브라우저에 로드된 웹 문서를 나타내는 객체

특징

- HTML 문서 전체 관리
- DOM 조작 가능
- 요소 생성 및 검색 가능

예시

```javascript
console.log(document.title);

console.log(document.URL);
```

요소 선택

```javascript
document.querySelector("div");
```

활용

- DOM 탐색
- 요소 생성
- 이벤트 등록

---

# Number 객체

## Number란?

숫자(Number) 자료형을 다루기 위한 객체

특징

- 숫자 변환 기능 제공
- 숫자 관련 메서드 제공

---

## toFixed()

소수점 자릿수 제어

예시

```javascript
const price = 956.821;

price.toFixed(2);
```

결과

```text
"956.82"
```

특징

- 반올림 수행
- 문자열 반환

활용

```javascript
const dollar = (won / 1400).toFixed(2);
```

---

# Math 객체

## Math란?

수학 계산을 위한 내장 객체

특징

- 생성 없이 바로 사용
- 수학 함수 제공
- 수학 상수 제공

---

## Math.max()

최댓값 반환

```javascript
Math.max(1, 5, 10);
```

결과

```text
10
```

---

## Math.min()

최솟값 반환

```javascript
Math.min(1, 5, 10);
```

결과

```text
1
```

---

## Spread와 함께 사용

```javascript
const nums = [-1, -4, -7, 11];

Math.max(...nums);
```

결과

```text
11
```

---

## Math.random()

0 이상 1 미만의 난수 생성

```javascript
Math.random();
```

예시 결과

```text
0.5382
```

---

## Math.floor()

소수점 이하 버림

```javascript
Math.floor(3.9);
```

결과

```text
3
```

---

## 랜덤 정수 생성

```javascript
function getRandom(min, max) {

    return Math.floor(
        Math.random() *
        (max - min + 1)
    ) + min;
}
```

예시

```javascript
getRandom(1, 10);
```

# Date 객체

## Date란?

날짜와 시간을 다루기 위한 객체

생성

```javascript
const today = new Date();
```

특징

- 현재 시간 저장
- 날짜 계산 가능
- 시간 계산 가능

---

## getDay()

요일 반환

```javascript
today.getDay();
```

반환값

| 값 | 요일 |
|------|------|
| 0 | 일요일 |
| 1 | 월요일 |
| 2 | 화요일 |
| 3 | 수요일 |
| 4 | 목요일 |
| 5 | 금요일 |
| 6 | 토요일 |

예시

```javascript
if (
    today.getDay() === 0 ||
    today.getDay() === 6
) {
    console.log("주말");
}
```

---

## 날짜 정보 가져오기

```javascript
today.getFullYear();

today.getMonth();

today.getDate();

today.getHours();

today.getMinutes();

today.getSeconds();
```

---

## setDate()

날짜 변경

```javascript
const date = new Date();

date.setDate(
    date.getDate() + 7
);
```

---

## toDateString()

날짜 문자열 반환

```javascript
date.toDateString();
```

결과 예시

```text
Tue Dec 31 2024
```

---

## getTime()

1970년 1월 1일부터 흐른 시간을 밀리초 단위로 반환

```javascript
Date.now();
```

또는

```javascript
date.getTime();
```

활용

```javascript
const diff =
    date2.getTime() -
    date1.getTime();
```

날짜 차이 계산 가능

---

# String 객체

## String이란?

문자열을 다루기 위한 객체

특징

- 문자열 변환
- 문자열 검색
- 문자열 수정

등의 기능 제공

---

## toUpperCase()

대문자 변환

```javascript
"hello".toUpperCase();
```

결과

```text
HELLO
```

---

## split()

문자열 분리

```javascript
"Kim,SW".split(",");
```

결과

```javascript
["Kim", "SW"]
```

---

## replace()

문자열 변경

```javascript
"hello".replace(
    "hello",
    "hi"
);
```

결과

```text
hi
```

---

## includes()

문자 포함 여부 확인

```javascript
"Daniel Kim".includes("Kim");
```

결과

```text
true
```

---

## trim()

공백 제거

```javascript
" hello ".trim();
```

결과

```text
hello
```

---

## indexOf()

문자 위치 검색

```javascript
"Daniel Kim".indexOf("Kim");
```

결과

```text
7
```

---

# JSON 객체

## JSON이란?

JavaScript Object Notation

데이터를 주고받기 위한 표준 형식

예시

```javascript
{
    "name": "Daniel",
    "age": 12
}
```

---

## JSON.stringify()

객체 → JSON 문자열

```javascript
const user = {
    name: "Daniel",
    age: 12
};

JSON.stringify(user);
```

결과

```javascript
'{"name":"Daniel","age":12}'
```

---

## JSON.parse()

JSON 문자열 → 객체

```javascript
const json =
    '{"name":"Daniel","age":12}';

JSON.parse(json);
```

결과

```javascript
{
    name: "Daniel",
    age: 12
}
```

---

## 활용

서버로 데이터 전송

```javascript
const body =
    JSON.stringify(user);
```

서버 응답 처리

```javascript
const data =
    JSON.parse(response);
```

# 핵심 정리

- JavaScript는 다양한 내장 객체를 제공
- window는 브라우저 창을 나타내는 전역 객체
- document는 HTML 문서를 관리하는 객체
- Number는 숫자 처리 기능 제공
- toFixed()는 소수점 자릿수 제어
- Math는 수학 계산을 위한 객체
- Math.max(), Math.min(), Math.random(), Math.floor()를 자주 사용
- Date는 날짜와 시간 처리 객체
- getDay(), getTime(), setDate() 등을 제공
- String은 문자열 조작 메서드를 제공
- split(), replace(), includes(), trim(), indexOf()를 자주 사용
- JSON은 객체와 문자열 간 변환에 사용
- JSON.stringify()는 직렬화, JSON.parse()는 역직렬화 수행
