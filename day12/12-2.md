# 배열 메서드(Array Methods)

## 배열 메서드란?

- 배열에 내장되어 있는 기능
- 배열의 데이터를 반복 처리하거나 가공할 때 사용
- ES6 이후 함수형 프로그래밍 스타일이 많이 사용되면서 중요성이 커짐

주요 배열 메서드

- forEach()
- map()
- filter()
- reduce()

---

# 고차 함수(Higher-Order Function)

## 고차 함수란?

- 함수를 인자로 받거나
- 함수를 반환하는 함수

예시

```javascript
function repeat(count, action) {

    for (let i = 0; i < count; i++) {
        action(i);
    }
}
```

사용

```javascript
repeat(3, console.log);
```

특징

- 함수를 값처럼 다룰 수 있음
- 배열 메서드 대부분이 고차 함수

---

# 콜백 함수(Callback Function)

## 콜백 함수란?

고차 함수에 인수로 전달되는 함수

예시

```javascript
repeat(3, function(index) {
    console.log(index);
});
```

여기서

```javascript
function(index) {
    console.log(index);
}
```

가 콜백 함수

---

## 콜백 함수 활용 예시

이벤트 핸들러도 콜백 함수

```javascript
button.addEventListener("click", function() {
    console.log("button clicked");
});
```

특징

- 특정 시점에 실행됨
- 함수 실행 시점을 다른 함수가 결정

---

# forEach()

## forEach란?

배열의 모든 요소를 순서대로 순회하며 콜백 함수를 실행

예시

```javascript
const numbers = [1, 2, 3, 4, 5];

numbers.forEach(function(num, index) {

    console.log(index, num);

});
```

출력

```text
0 1
1 2
2 3
3 4
4 5
```

---

## 특징

- 배열 길이만큼 반복
- 각 요소와 인덱스를 전달
- 반환값 없음

```javascript
numbers.forEach((num, index) => {
    console.log(num);
});
```

활용

- 단순 반복
- 화면 출력
- 데이터 순회

---

# map()

## map이란?

각 요소를 변환한 결과를 모아 새로운 배열 반환

예시

```javascript
const numbers = [1, 2, 3, 4, 5];

const doubled = numbers.map(num => num * 2);
```

결과

```javascript
[2, 4, 6, 8, 10]
```

---

## 특징

- 새로운 배열 생성
- 원본 배열 변경 없음
- 반환값이 새 배열의 요소가 됨

```javascript
const names = ["kim", "lee"];

const upperNames = names.map(name =>
    name.toUpperCase()
);
```

결과

```javascript
["KIM", "LEE"]
```

---

# filter()

## filter란?

조건을 만족하는 요소만 모아 새로운 배열 반환

예시

```javascript
const numbers = [1, 2, 3, 4, 5];

const evenNumbers =
    numbers.filter(num => num % 2 === 0);
```

결과

```javascript
[2, 4]
```

---

## 특징

- 조건 결과를 boolean 값으로 반환
- true인 요소만 유지
- 새로운 배열 생성
- 원본 배열 변경 없음

예시

```javascript
const users = [
    { age: 18 },
    { age: 25 },
    { age: 30 }
];

const adults =
    users.filter(user => user.age >= 20);
```

---

# reduce()

## reduce란?

배열 요소를 하나씩 누적 계산하여 최종 결과 반환

예시

```javascript
const numbers = [1, 2, 3, 4, 5];

const sum = numbers.reduce(
    (accumulator, currentValue) =>
        accumulator + currentValue,
    0
);
```

결과

```javascript
15
```

---

## reduce 동작 과정

초기값

```javascript
0
```

계산 과정

```text
0 + 1 = 1
1 + 2 = 3
3 + 3 = 6
6 + 4 = 10
10 + 5 = 15
```

최종 반환

```javascript
15
```

---

## 매개변수

```javascript
array.reduce(
    (accumulator, currentValue) => {},
    initialValue
);
```

### accumulator

이전 단계까지의 누적값

### currentValue

현재 요소 값

### initialValue

초기값

---

## 활용 예시

배열 합계

```javascript
const total =
    numbers.reduce(
        (sum, num) => sum + num,
        0
    );
```

최댓값 찾기

```javascript
const max =
    numbers.reduce(
        (a, b) => Math.max(a, b)
    );
```

문자열 합치기

```javascript
const text =
    ["A", "B", "C"].reduce(
        (acc, cur) => acc + cur,
        ""
    );
```

결과

```text
ABC
```

# 배열 메서드 비교

| 메서드 | 반환값 | 목적 |
|----------|----------|----------|
| forEach | 없음 | 반복 실행 |
| map | 새로운 배열 | 데이터 변환 |
| filter | 새로운 배열 | 조건 필터링 |
| reduce | 누적 결과 | 집계 및 계산 |

---

# 핵심 정리

- 배열 메서드는 콜백 함수를 이용하여 배열 데이터를 처리
- 고차 함수는 함수를 인자로 받거나 반환하는 함수
- 콜백 함수는 고차 함수에 전달되는 함수
- forEach()는 배열을 순회하지만 반환값이 없음
- map()은 각 요소를 변환하여 새로운 배열 생성
- filter()는 조건을 만족하는 요소만 새로운 배열로 반환
- reduce()는 배열을 누적 계산하여 하나의 결과 반환
- map, filter, reduce는 원본 배열을 변경하지 않음
- 배열 데이터 가공 시 가장 많이 사용하는 메서드는 map, filter, reduce
