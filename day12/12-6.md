# async / await

# async/await란?

## Promise의 단점

Promise는 비동기 처리를 할 수 있지만 체이닝이 길어질수록 가독성이 떨어질 수 있다.

예시

```javascript
fetchData()

    .then(data1 => {

        return fetchData2(data1);

    })

    .then(data2 => {

        return fetchData3(data2);

    })

    .then(data3 => {

        console.log(data3);

    })

    .catch(error => {

        console.log(error);

    });
```

문제점

- 코드가 길어짐
- 들여쓰기 증가
- 흐름 파악이 어려움

---

## async/await 등장

ES8(ES2017)부터 async/await 문법 제공

특징

- Promise 기반
- 동기 코드처럼 작성 가능
- 가독성 향상

# async/await 사용

## 기본 형태

```javascript
async function fetchData() {

    const data =
        await getData();

    console.log(data);

}
```

특징

- 비동기 코드를 순차적으로 작성 가능
- Promise 체이닝 감소

# await

## await란?

Promise가 처리될 때까지 기다리는 키워드

```javascript
const result =
    await promise;
```

동작

```text
Promise 실행
↓
완료까지 대기
↓
resolve 값 반환
```

---

## 예시

```javascript
async function getUser() {

    const user =
        await fetchUser();

    console.log(user);

}
```

특징

- Promise가 끝날 때까지 기다림
- resolve된 값을 반환

---

## 반환값

```javascript
const value =
    await Promise.resolve(100);
```

결과

```javascript
100
```

# async

## async란?

함수를 비동기 함수로 선언하는 키워드

```javascript
async function test() {

}
```

또는

```javascript
const test =
    async () => {

    };
```

---

## await 사용 조건

await는 반드시 async 함수 내부에서만 사용 가능

가능

```javascript
async function test() {

    await fetchData();

}
```

불가능

```javascript
await fetchData();
```

결과

```text
SyntaxError
```

---

# async 함수의 반환값

## 특징

async 함수는 항상 Promise 반환

예시

```javascript
async function square(n) {

    return n * n;

}
```

호출

```javascript
square(3);
```

실제 반환

```javascript
Promise {
    9
}
```

---

## 사용 예시

```javascript
async function square(n) {

    return n * n;

}

square(3)
    .then(result => {

        console.log(result);

    });
```

결과

```text
9
```

# Promise vs async/await

## Promise 방식

```javascript
fetchData()

    .then(data => {

        console.log(data);

    })

    .catch(error => {

        console.log(error);

    });
```

---

## async/await 방식

```javascript
async function run() {

    try {

        const data =
            await fetchData();

        console.log(data);

    } catch (error) {

        console.log(error);

    }

}
```

장점

- 읽기 쉬움
- 동기 코드와 유사
- 흐름 파악 용이

# 예외 처리(Exception Handling)

## 예외란?

프로그램 실행 중 발생하는 오류

예시

```javascript
JSON.parse(
    "{name: 'john'}"
);
```

결과

```text
SyntaxError
```

---

## 예외 처리 필요성

문제점

```text
에러 발생
↓
프로그램 종료
```

예외 처리를 통해

```text
에러 발생
↓
대응
↓
프로그램 계속 실행
```

가능

# try ... catch

## 기본 문법

```javascript
try {

    // 실행 코드

} catch (error) {

    // 에러 처리

}
```

---

## 동작 과정

```javascript
try {

    JSON.parse(
        "{name: 'john'}"
    );

} catch (error) {

    console.log(error);

}
```

실행 순서

```text
에러 발생
↓
catch 이동
↓
에러 처리
```

---

## 특징

- try 단독 사용 불가
- catch와 함께 사용
- 에러 발생 시 catch 실행

---

# async/await 예외 처리

## try-catch 사용

```javascript
async function fetchData() {

    try {

        const data =
            await getData();

        console.log(data);

    } catch (error) {

        console.error(error);

    }

}
```

특징

- await 중 발생한 reject 처리 가능
- Promise의 catch 역할 수행

---

# finally

## finally란?

에러 여부와 관계없이 항상 실행

```javascript
try {

    // 코드

} catch (error) {

    // 에러 처리

} finally {

    // 항상 실행

}
```

---

## 예시

```javascript
try {

    JSON.parse(
        "{name: 'john'}"
    );

} catch (error) {

    console.log(error);

} finally {

    console.log(
        "JSON 처리 종료"
    );

}
```

결과

```text
SyntaxError
JSON 처리 종료
```

---

## 활용 예시

```javascript
async function getUser() {

    try {

        const user =
            await fetchUser();

        console.log(user);

    } catch (error) {

        console.log(error);

    } finally {

        console.log(
            "요청 종료"
        );

    }

}
```

---

# 핵심 정리

- Promise는 체이닝이 길어질수록 가독성이 떨어질 수 있음
- async/await는 비동기 코드를 동기 코드처럼 작성 가능
- await는 Promise가 완료될 때까지 기다림
- await는 resolve된 값을 반환
- await는 async 함수 내부에서만 사용 가능
- async 함수는 항상 Promise를 반환
- async 함수의 return 값은 자동으로 resolve 처리됨
- async/await는 Promise 기반 문법
- 예외 처리는 try ... catch 문 사용
- async/await에서는 Promise reject를 try-catch로 처리 가능
- finally는 성공/실패 여부와 관계없이 항상 실행
- async/await는 Promise보다 코드 흐름을 읽기 쉽고 유지보수가 편리함
