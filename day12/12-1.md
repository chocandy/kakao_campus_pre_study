# ES6 문법

## ES6란?

- JavaScript는 ECMAScript라는 표준 사양을 기반으로 발전해옴
- ES6(ECMAScript 2015)는 2015년에 발표된 버전
- 현대 JavaScript 개발에서 사용하는 대부분의 핵심 문법이 ES6에서 도입됨

주요 문법

- let, const
- 화살표 함수 (Arrow Function)
- 구조 분해 할당 (Destructuring Assignment)
- Spread 문법
- 템플릿 리터럴
- 옵셔널 체이닝
- 프로퍼티/메서드 축약
- 배열 메서드

---

# let과 const

## let

값 변경이 가능한 변수 선언

```javascript
let fruit = "오렌지";

fruit = "포도";
```

선언 후 나중에 값 할당 가능

```javascript
let user;

user = "hellobit";
```

특징

- 재할당 가능
- 블록 레벨 스코프 지원

---

## const

값 변경이 불가능한 변수 선언

```javascript
const fruit = "오렌지";
```

재할당 불가

```javascript
fruit = "포도"; // Error
```

선언과 초기화를 반드시 동시에 수행

```javascript
const user; // Error
```

특징

- 재할당 불가
- 선언 즉시 초기화 필요
- 블록 레벨 스코프 지원

---

## var vs let, const

### var의 문제점

변수 중복 선언 허용

```javascript
var fruit = "오렌지";
var fruit = "포도";
```

의도치 않은 값 변경 가능

---

### let, const

중복 선언 불가능

```javascript
let fruit = "오렌지";
let fruit = "포도"; // Error
```

```javascript
const user = "hellobit";
const user = "caterpillar"; // Error
```

권장 사항

- 기본적으로 const 사용
- 변경이 필요한 경우만 let 사용
- var 사용 지양

---

# 스코프(Scope)

## 스코프란?

- 변수를 참조할 수 있는 유효 범위
- 변수의 접근 가능 영역을 결정

---

## 전역 스코프(Global Scope)

가장 바깥쪽 영역

```javascript
let a = 10;
```

특징

- 어디서든 접근 가능

---

## 지역 스코프(Local Scope)

함수 또는 블록 내부

```javascript
function test() {
    let a = 10;
}
```

특징

- 해당 영역 내부에서만 접근 가능

---

# 함수 레벨 스코프 vs 블록 레벨 스코프

## 함수 레벨 스코프 (var)

함수 내부만 지역 스코프로 인정

```javascript
if (true) {
    var num = 10;
}

console.log(num);
```

출력

```text
10
```

if 블록 밖에서도 접근 가능

---

## 블록 레벨 스코프 (let, const)

중괄호 내부를 지역 스코프로 인정

```javascript
if (true) {
    let num = 10;
}

console.log(num);
```

출력

```text
ReferenceError
```

특징

- if
- for
- while
- switch

등의 블록 내부에서만 사용 가능

---

# 스코프 체인(Scope Chain)

## 스코프 체인이란?

- 모든 스코프가 계층적으로 연결된 구조
- 변수 탐색 시 현재 스코프부터 상위 스코프로 이동하며 검색

예시

```javascript
let global = 10;

function outer() {

    let local1 = 20;

    function inner() {

        let local2 = 30;

        console.log(local2);
        console.log(local1);
        console.log(global);
    }
}
```

탐색 순서

```text
현재 스코프
↓
부모 스코프
↓
전역 스코프
```

---

# 렉시컬 스코프(Lexical Scope)

## 렉시컬 스코프란?

함수를 정의한 위치에 따라 상위 스코프가 결정되는 방식

```javascript
let x = 10;

function func1() {

    let x = 20;

    func2();
}

function func2() {
    console.log(x);
}
```

출력

```text
10
```

특징

- JavaScript가 사용하는 방식
- 함수 호출 위치가 아닌 선언 위치 기준

---

# 화살표 함수 (Arrow Function)

## 화살표 함수란?

ES6에서 추가된 함수 선언 방식

기존 함수

```javascript
function add(a, b) {
    return a + b;
}
```

화살표 함수

```javascript
const add = (a, b) => {
    return a + b;
};
```

간단한 표현

```javascript
const add = (a, b) => a + b;
```

특징

- 코드가 간결함
- 콜백 함수 작성 시 자주 사용

---

# 옵셔널 체이닝(Optional Chaining)

## 문제 상황

존재하지 않는 프로퍼티 접근 시 에러 발생

```javascript
user.contact.email;
```

```text
TypeError
```

---

## 해결 방법

```javascript
user.contact?.email;
```

특징

- 값이 없으면 에러 대신 undefined 반환

결과

```javascript
undefined
```

활용

- API 응답 처리
- 중첩 객체 접근

---

# 구조 분해 할당(Destructuring Assignment)

## 객체 구조 분해

기존 방식

```javascript
const name = user.name;
const age = user.age;
```

구조 분해 할당

```javascript
const { name, age } = user;
```

---

## 이름 변경

```javascript
const { name: userName } = user;
```

---

## 기본값 설정

```javascript
const { age = 20 } = user;
```

---

## Rest Syntax

```javascript
const {
    name,
    ...rest
} = user;
```

결과

```javascript
rest
```

↓

```javascript
{
    age: 20,
    city: "Seoul"
}
```

---

## 배열 구조 분해

```javascript
const arr = [10, 20, 30];

const [a, b, c] = arr;
```

---

## 배열 Rest

```javascript
const [first, ...rest] = arr;
```

---

# Spread 문법(Spread Syntax)

## 배열 펼치기

```javascript
const arr1 = [1, 2];
const arr2 = [3, 4];

const result = [...arr1, ...arr2];
```

결과

```javascript
[1, 2, 3, 4]
```

---

## 함수 인수 전달

```javascript
const numbers = [1, 2, 3];

console.log(...numbers);
```

---

## 객체 복사

```javascript
const user = {
    name: "Kim",
    age: 20
};

const copy = {
    ...user
};
```

특징

- 배열 결합
- 객체 복사
- 객체 병합

에 자주 사용

---

# 템플릿 리터럴(Template Literal)

## 문자열 보간

기존 방식

```javascript
"Hello " + name
```

템플릿 리터럴

```javascript
`Hello ${name}`
```

---

## 표현식 사용

```javascript
const a = 10;
const b = 20;

`${a + b}`
```

결과

```text
30
```

특징

- 가독성 향상
- 문자열 조합이 편리함

---

# 프로퍼티/메서드 축약

## 프로퍼티 축약

기존 방식

```javascript
const name = "Kim";
const age = 20;

const user = {
    name: name,
    age: age
};
```

축약 방식

```javascript
const user = {
    name,
    age
};
```

---

## 메서드 축약

기존 방식

```javascript
const user = {
    hello: function() {
        console.log("Hello");
    }
};
```

축약 방식

```javascript
const user = {
    hello() {
        console.log("Hello");
    }
};
```

---

# 핵심 정리

- ES6는 현대 JavaScript의 핵심 문법이 도입된 버전
- 변수 선언은 var 대신 let, const 사용
- const를 기본으로 사용하고 필요할 때만 let 사용
- let, const는 블록 레벨 스코프 지원
- JavaScript는 렉시컬 스코프를 사용
- 화살표 함수는 함수를 간결하게 작성 가능
- 옵셔널 체이닝은 없는 프로퍼티 접근 시 에러를 방지
- 구조 분해 할당은 객체와 배열 값을 쉽게 추출
- Spread 문법은 배열과 객체를 펼치거나 복사할 때 사용
- 템플릿 리터럴은 문자열 조합을 편리하게 작성
- 프로퍼티/메서드 축약으로 객체 작성이 간결해짐
