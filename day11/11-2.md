# 이벤트(Event)

## 이벤트란?

- 웹 브라우저가 HTML 요소에 대해 발생시킨 사건(Event)
- 사용자의 행동이나 브라우저 상태 변화에 의해 발생
- JavaScript는 이벤트가 발생했을 때 특정 동작을 수행할 수 있음

예시

- 버튼 클릭
- 키보드 입력
- 마우스 이동
- 폼 제출
- 페이지 로드

---

키보드 입력과 관련된 이벤트

form 태그와 관련된 이벤트

# 이벤트 핸들러(Event Handler)

## 이벤트 핸들러란?

- 이벤트가 발생했을 때 실행되는 함수
- 특정 이벤트와 연결되어 있다가 이벤트 발생 시 자동 실행됨

예시

```javascript
var button = document.getElementById("btn");

button.addEventListener("click", function () {
    console.log("button clicked");
});
```

동작 과정

1. 버튼 클릭
2. click 이벤트 발생
3. 등록된 이벤트 핸들러 실행
4. 콘솔에 메시지 출력

---

# 이벤트 핸들러 등록 방법

## 1. HTML 속성 방식

HTML 태그에 직접 이벤트 작성

```html
<button onclick="handleClick()">
    Click Event
</button>

<script>
function handleClick() {
    console.log("button clicked");
}
</script>
```

또는

```html
<button onclick="console.log('button clicked')">
    Click Event
</button>
```

특징

- HTML 내부에 JavaScript 코드 작성
- 구조와 동작이 섞이게 됨
- 유지보수가 어려움
- 현재는 권장되지 않는 방식

---

## 2. Node 객체 프로퍼티 방식

JavaScript에서 이벤트 등록

```javascript
var button = document.getElementById("btn");

button.onclick = function () {
    console.log("button clicked");
};
```

특징

- HTML과 JavaScript 분리 가능
- 이벤트를 코드에서 관리 가능
- 동일 이벤트에 하나의 핸들러만 등록 가능

---

## 3. addEventListener() 방식

가장 많이 사용하는 이벤트 등록 방법

```javascript
var button = document.getElementById("btn");

button.addEventListener("click", function () {
    console.log("button clicked");
});
```

특징

- 첫 번째 인수 : 이벤트명
- 두 번째 인수 : 실행할 함수
- 이벤트명에는 on을 붙이지 않음

예시

```javascript
button.addEventListener("click", handleClick);

function handleClick() {
    console.log("clicked");
}
```

---

# addEventListener() 활용

## 클릭 이벤트

```javascript
button.addEventListener("click", function () {
    alert("클릭되었습니다.");
});
```

---

## 키 입력 이벤트

```javascript
document.addEventListener("keydown", function () {
    console.log("키 입력");
});
```

---

## 폼 제출 이벤트

```javascript
form.addEventListener("submit", function () {
    console.log("폼 제출");
});
```

---

# 이벤트 등록 방식 비교

| 방식 | 특징 |
|--------|--------|
| HTML 속성 | HTML에 직접 작성, 권장되지 않음 |
| Node 프로퍼티 | 간단하지만 이벤트 하나만 등록 가능 |
| addEventListener | 가장 권장되는 방식, 여러 이벤트 등록 가능 |

---

# 핵심 정리

- 이벤트는 브라우저에서 발생하는 사건(Event)
- JavaScript는 이벤트 발생 시 원하는 동작을 수행할 수 있음
- 주요 이벤트 종류는 마우스 이벤트, 키 이벤트, 폼 이벤트가 있음
- 이벤트 발생 시 실행되는 함수를 이벤트 핸들러라고 함
- 이벤트 등록 방법은 HTML 속성 방식, Node 프로퍼티 방식, addEventListener 방식이 있음
- addEventListener()가 가장 많이 사용되며 권장되는 방법
- addEventListener()의 첫 번째 인수는 이벤트명, 두 번째 인수는 핸들러 함수
- 이벤트명을 작성할 때는 on을 붙이지 않음
