# DOM과 이벤트

## DOM(Document Object Model)

- HTML 문서를 객체 형태로 표현한 구조
- 브라우저는 HTML을 해석하여 DOM 트리(DOM Tree)를 생성
- JavaScript는 DOM을 통해 HTML 요소를 조회하고 조작할 수 있음
- DOM은 부모-자식 관계를 가지는 트리(Tree) 구조로 구성됨

### DOM 트리 구조

- HTML 문서의 각 태그는 Node 객체로 변환됨
- 태그 간 포함 관계가 부모-자식 관계로 표현됨
- JavaScript는 이 Node들을 통해 웹 페이지를 동적으로 제어함

예시

```html
<html>
  <body>
    <article>
      <header>header</header>
      <section>section 1</section>
    </article>
  </body>
</html>
```

트리 구조

```text
html
 └─ body
     └─ article
         ├─ header
         └─ section
```

---

## Node 객체

- DOM에서 정보를 저장하는 기본 단위
- HTML 문서의 모든 요소는 Node 객체로 관리됨
- Node들이 연결되어 Node Tree를 구성함

### 주요 Node 종류

- document
- element
- attribute
- text

---

## Document 객체

- 현재 웹 페이지 전체를 의미하는 객체
- DOM에 접근할 때 시작점 역할 수행
- HTML 요소 선택, 생성, 이벤트 등록 등의 기능 제공

예시

```javascript
document
```

---

## Element 객체

- 개별 HTML 태그를 의미
- 요소의 내용, 속성, 스타일 등을 조작할 수 있음

예시

```javascript
document.querySelector("#title");
```

### document / element 객체의 역할

- HTML 요소 선택
- HTML 요소 생성
- HTML 이벤트 핸들러 등록
- HTML 요소 내용 변경
- HTML 요소 스타일 변경

---

# HTML 요소 선택

## 요소 하나 선택

### getElementById()

```javascript
document.getElementById("box");
```

- id 기준으로 요소 선택

### querySelector()

```javascript
document.querySelector("#box");
document.querySelector(".item");
document.querySelector("header");
```

- CSS 선택자 사용
- 선택된 요소 중 첫 번째 요소 반환

---

## 여러 요소 선택

### getElementsByClassName()

```javascript
document.getElementsByClassName("list-item");
```

- 해당 클래스를 가진 모든 요소 선택

### getElementsByName()

```javascript
document.getElementsByName("email");
```

- 해당 name 속성을 가진 모든 요소 선택

### querySelectorAll()

```javascript
document.querySelectorAll("ul li");
```

- CSS 선택자로 여러 요소 선택
- NodeList 형태로 반환

예시

```javascript
let items = document.querySelectorAll(".item");

for (const item of items) {
    console.log(item);
}
```

# HTML 요소 조작

## 스타일 변경

### style 속성 사용

```javascript
let item = document.querySelector(".even");

item.style.color = "red";
item.style.backgroundColor = "yellow";
```

활용 예시

- 글자색 변경
- 배경색 변경
- 크기 변경
- 위치 변경

---

## innerHTML

HTML 코드 자체를 변경

```javascript
let text = document.getElementById("text");

text.innerHTML = "<span>안녕하세요</span>";
```

특징

- HTML 태그 포함 가능
- 기존 내용을 덮어씀

---

## innerText

텍스트만 변경

```javascript
let text = document.getElementById("text");

text.innerText = "Hello Elice";
```

특징

- HTML 태그를 해석하지 않음
- 순수 텍스트만 출력

---

## 속성 조회 및 변경

### getAttribute()

속성 조회

```javascript
input.getAttribute("placeholder");
```

### setAttribute()

속성 변경

```javascript
input.setAttribute("min", "20");
```

활용 예시

- placeholder 변경
- min/max 설정
- href 변경
- src 변경

---

## class 조작

```javascript
element.classList.add("active");

element.classList.remove("active");

element.classList.toggle("active");
```

활용 예시

- 버튼 활성화
- 메뉴 열기/닫기
- 상태 변경

---

# HTML 요소 생성

## createElement()

새로운 HTML 요소 생성

```javascript
let div = document.createElement("div");
```

특징

- 메모리 상에만 생성
- 아직 화면에는 표시되지 않음

---

# HTML 요소 추가

## appendChild()

생성한 요소를 DOM에 추가

```javascript
let div = document.createElement("div");

document.body.appendChild(div);
```

특징

- 부모 요소의 마지막 자식으로 추가
- 화면에 실제로 표시됨

예시

```javascript
let li = document.createElement("li");

li.innerText = "새 항목";

document.querySelector("ul").appendChild(li);
```

# 핵심 정리

- DOM은 HTML 문서를 객체 형태로 표현한 구조
- 브라우저는 HTML을 DOM Tree로 변환하여 관리
- document 객체를 통해 DOM에 접근
- element 객체를 통해 HTML 요소를 조작
- 요소 선택은 getElementById(), querySelector(), querySelectorAll() 등을 사용
- style로 CSS 변경 가능
- innerHTML은 HTML 자체 변경
- innerText는 텍스트만 변경
- getAttribute(), setAttribute()로 속성 조회 및 수정 가능
- createElement()로 새로운 요소 생성
- appendChild()로 DOM에 추가하여 화면에 표시
