# DOM과 이벤트 활용

# 이벤트 객체(Event Object)

## 이벤트 객체란?

- 이벤트 핸들러 함수의 첫 번째 인수로 전달되는 객체
- 발생한 이벤트에 대한 정보와 기능을 포함
- 이벤트 종류에 따라 다양한 정보를 제공

예시

```javascript
button.addEventListener("click", function(event) {
    console.log(event);
});
```

---

# 이벤트 객체 활용

## 마우스 정보

마우스 이벤트에서는 클릭 위치 등의 정보를 얻을 수 있음

예시

```javascript
box.addEventListener("click", function(event) {
    console.log(event.clientX);
    console.log(event.clientY);
});
```

주요 속성

- event.clientX : 클릭한 X 좌표
- event.clientY : 클릭한 Y 좌표

활용 예시

- 드래그 기능
- 그림판 구현
- 마우스 위치 추적

---

## 키보드 정보

키보드 이벤트에서는 입력된 키 정보를 확인할 수 있음

예시

```javascript
window.addEventListener("keypress", function(event) {
    console.log(event.key);
});
```

주요 속성

- event.key : 입력한 키 값

예시 결과

```text
A
Enter
Space
1
```

활용 예시

- 단축키 구현
- 게임 조작
- 입력 검증

---

## event.target

이벤트가 실제로 발생한 요소를 반환

예시

```javascript
box.addEventListener("click", function(event) {
    console.log(event.target);
});
```

특징

- 이벤트가 발생한 HTML 요소 확인 가능
- 이벤트 위임(Event Delegation)에 자주 사용

---

## preventDefault()

브라우저의 기본 동작을 막음

### 기본 동작 예시

form 태그의 submit 버튼 클릭

```text
폼 제출
↓
페이지 새로고침
```

### 기본 동작 막기

```javascript
loginForm.addEventListener("submit", function(event) {
    event.preventDefault();

    console.log("아이디:", idInput.value);
    console.log("비밀번호:", passwordInput.value);
});
```

활용 예시

- 로그인 폼 처리
- 회원가입 검증
- AJAX 요청 처리

# 이벤트 핸들러 제거

## removeEventListener()

등록된 이벤트 핸들러 제거

예시

```javascript
function handleClick(event) {
    console.log("clicked");
}

button.addEventListener("click", handleClick);

button.removeEventListener("click", handleClick);
```

특징

- addEventListener()로 등록한 이벤트 제거 가능
- 동일한 함수 참조가 필요함

# 이벤트 전파(Event Propagation)

## 이벤트 전파란?

- 이벤트가 발생하면 해당 요소에서만 끝나는 것이 아님
- DOM 트리를 따라 부모 요소로 전달됨
- 이를 이벤트 전파(Event Propagation)라고 함

예시 구조

```text
window
 └─ document
     └─ html
         └─ body
             └─ parent1
                 └─ parent2
                     └─ parent3
                         └─ button
```

버튼 클릭 시

```text
button
parent3
parent2
parent1
body
html
document
window
```

모든 요소가 이벤트를 감지할 수 있음

---

# 이벤트 전파 단계

## 1. Capturing Phase

상위 요소에서 하위 요소 방향으로 이동

```text
window
↓
document
↓
html
↓
body
↓
button
```

이벤트 등록

```javascript
parent.addEventListener(
    "click",
    function(event) {
        console.log("capturing");
    },
    true
);
```

특징

- addEventListener()의 세 번째 인수에 true 전달
- 캡처링 단계에서 이벤트 처리

---

## 2. Target Phase

실제 이벤트가 발생한 요소 단계

예시

```text
button 클릭
↓
button 이벤트 실행
```

특징

- 이벤트가 실제 발생한 요소에서 실행
- event.target과 관련

---

## 3. Bubbling Phase

하위 요소에서 상위 요소 방향으로 이동

```text
button
↑
parent3
↑
parent2
↑
parent1
↑
body
↑
html
```

예시

```javascript
parent.addEventListener("click", function(event) {
    console.log("bubbling");
});
```

특징

- 기본 동작
- 세 번째 인수를 생략하면 Bubbling Phase에서 실행

---

# stopPropagation()

## 이벤트 전파 중단

버튼 클릭 시 부모 요소까지 이벤트가 전달되는 것을 막음

예시

```javascript
button.addEventListener("click", function(event) {

    event.stopPropagation();

    console.log("button clicked");
});
```

동작

```text
button 클릭
↓
button 이벤트 실행
↓
전파 중단
↓
부모 이벤트 실행 안됨
```

활용 예시

- 모달 창 닫기 방지
- 메뉴 이벤트 분리
- 의도하지 않은 부모 이벤트 실행 방지

---

# 핵심 정리

- 이벤트 객체(event)는 이벤트 발생 시 자동으로 전달되는 객체
- event.clientX, clientY로 마우스 위치 확인 가능
- event.key로 입력된 키 확인 가능
- event.target으로 실제 이벤트 발생 요소 확인 가능
- event.preventDefault()는 브라우저 기본 동작을 막음
- removeEventListener()로 이벤트 핸들러 제거 가능
- 이벤트는 DOM 트리를 따라 전파됨(Event Propagation)
- 이벤트 전파는 Capturing → Target → Bubbling 순서로 진행
- addEventListener()의 세 번째 인수 true는 Capturing 단계에서 처리
- 기본적으로 이벤트는 Bubbling 단계에서 처리됨
- event.stopPropagation()은 부모 요소로의 이벤트 전파를 중단함
