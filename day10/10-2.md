# JavaScript 기초 다지기

## 산술 연산자

### 기본 산술 연산

```javascript
+
-
*
/
%
```

| 연산자 | 의미 |
|----------|----------|
| + | 덧셈 |
| - | 뺄셈 |
| * | 곱셈 |
| / | 나눗셈 |
| % | 나머지 |

### 예시

```javascript
let a = 10;
let b = 3;

console.log(a + b); // 13
console.log(a - b); // 7
console.log(a * b); // 30
console.log(a / b); // 3.3333
console.log(a % b); // 1
```

### 나머지 연산

```javascript
10 % 3
```

결과

```javascript
1
```

- 나눈 뒤 나머지를 반환
- 짝수/홀수 판별에 자주 사용

# 삼항 연산자

## 기본 문법

```javascript
조건 ? 참일때 : 거짓일때
```

### 예시

```javascript
let result =
    age >= 20
    ? "성인"
    : "미성년자";
```

### if else 변환

```javascript
if (age >= 20) {
    result = "성인";
} else {
    result = "미성년자";
}
```

## for 문

### 기본 구조

```javascript
for (
    초기식;
    조건식;
    증감식
) {

}
```

### 예시

```javascript
for (
    let i = 0;
    i < 5;
    i++
) {
    console.log(i);
}
```

결과

```javascript
0
1
2
3
4
```

---

## for in

### 객체 순회

```javascript
for (let key in obj) {

}
```

### 예시

```javascript
const user = {
    name: "Elice",
    age: 20
};

for (let key in user) {
    console.log(key);
}
```

결과

```javascript
name
age
```

### 특징

- 객체(Object) 순회에 사용

---

```javascript
30
```

```javascript
String
Map
Set
NodeList
```

## forEach

### 배열 전용 메소드

```javascript
arr.forEach(
    (value, index) => {

    }
);
```

### 예시

```javascript
const arr =
    ["A", "B", "C"];

    (value, index) => {
        console.log(index, value);
```

# 핵심 정리

- 산술 연산자는 +, -, *, /, %를 사용한다.
- ++, --는 값을 1 증가 또는 감소시킨다.
- 전위 연산은 먼저 연산 후 대입, 후위 연산은 먼저 대입 후 연산한다.
- == 보다 === 사용을 권장한다.
- &&는 AND, ||는 OR, !는 NOT 연산자이다.
- 조건문은 if, if else, if else if를 사용한다.
- false, 0, '', null, undefined, NaN은 Falsy이다.
- 삼항 연산자는 간단한 조건 분기에 사용한다.
- for는 일반 반복문, for in은 객체 순회, for of는 iterable 순회에 사용한다.
- forEach는 배열 전용 순회 메소드이다.
- Object.keys(), Object.values()로 객체 데이터를 순회할 수 있다.
