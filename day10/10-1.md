# JavaScript 기초 배우기

## JavaScript 소개

### JavaScript란?

- 객체(Object) 기반의 스크립트 언어
- HTML은 구조, CSS는 디자인, JavaScript는 동작을 담당
- 웹 브라우저에서 주로 실행되며 Node.js를 통해 서버 개발도 가능
- 대부분의 브라우저에 JavaScript 인터프리터가 내장되어 있음

### JavaScript의 특징

- 객체 기반 프로그래밍 지원
- 동적 타입 언어
- 인터프리터 방식으로 실행
- 객체지향 프로그래밍(OOP)과 함수형 프로그래밍(FP) 모두 가능

### JavaScript로 할 수 있는 것

- HTML 요소 추가, 삭제, 수정
- DOM 조작
- Canvas, WebGL을 이용한 2D·3D 그래픽
- 오디오 및 비디오 제어
- API 활용

### JavaScript 활용 분야

- 웹 사이트 개발
- 서버 개발(Node.js)
- 웹 애플리케이션
- 모바일 앱
- 데스크탑 앱

# JavaScript 출력

## Template Literals

### 기존 문자열 연결

```javascript
let age = 30;

let str = "나이는 " + age + "살입니다.";
```

### 템플릿 리터럴

```javascript
let age = 30;

let str = `나이는 ${age}살입니다.`;
```

### 특징

- ES6부터 도입
- 백틱(``) 사용
- `${}` 안에 변수나 표현식 삽입 가능
- 문자열 연결보다 가독성이 좋음

# 변수

## 변수란?

- 데이터를 저장하는 공간
- 이름을 통해 데이터 접근
- 하나의 변수에는 하나의 값 저장
- 재할당 가능

### 예시

```javascript
let name = "Elice";
```

---

## 변수 선언 키워드

### let

```javascript
let age = 20;
```

#### 특징

- 재선언 불가
- 재할당 가능
- Block Scope

---

### const

```javascript
const PI = 3.14;
```

#### 특징

- 재선언 불가
- 재할당 불가
- 선언과 초기화 동시에 진행
- Block Scope

---

### var

```javascript
var name = "Elice";
```

#### 특징

- 재선언 가능
- 함수 스코프(Function Scope)
- ES6 이전 방식
- 사용 비추천

---

## 변수 이름 규칙

### 규칙

- 숫자로 시작 불가

# 객체(Object)

## 객체란?

- key와 value의 집합
- 여러 데이터를 하나로 묶어서 관리

### 생성

```javascript
const user = {
    name: "Elice",
    age: 20
};
```

### 구조

```javascript
{
    key: value
}
```

### Property

```javascript
name: "Elice"
```

---

## Method

### 메소드란?

- 객체 안에 저장된 함수

```javascript
const user = {
    hello: function() {
        console.log("hello");
    }
};
```

---

# 배열(Array)

## 배열이란?

- 순서가 있는 데이터 집합
- 여러 값을 하나의 변수에 저장

### 생성

```javascript
const arr = [1, 2, 3];
```

### 특징

- 인덱스는 0부터 시작
- 자료형 혼합 가능

```javascript
[
    "text",
    1,
    true,
    null
]
```

# 함수(Function)

## 함수란?

- 특정 작업을 수행하는 코드 묶음

### 함수 선언

```javascript
function hello() {
    console.log("hello");
}
```

### 반환값

```javascript
function add(a, b) {
    return a + b;
}
```

---

## 화살표 함수

### 기본 함수

```javascript
function add(a, b) {
    return a + b;
}
```

### 화살표 함수

```javascript
const add = (a, b) => {
    return a + b;
};
```

### 한 줄 작성

```javascript
const add = (a, b) => a + b;
```

### 특징

- ES6 도입
- 코드가 간결함

# 핵심 정리

- JavaScript는 웹의 동작을 담당하는 객체 기반 스크립트 언어이다.
- 변수 선언은 let, const 사용을 권장한다.
- 기본 데이터 타입은 Number, String, Boolean, Undefined가 있다.
- 객체(Object)는 key-value 형태로 데이터를 저장한다.
- 배열(Array)은 순서가 있는 데이터 집합이다.
- 함수(Function)는 작업을 수행하는 코드 블록이다.
- 화살표 함수는 ES6에서 추가된 간결한 함수 표현식이다.
- 문자열, 배열, Math 객체는 다양한 메소드를 제공한다.
- Number(), String(), Boolean(), parseInt()로 명시적 형변환이 가능하다.
