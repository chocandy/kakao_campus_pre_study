# AWS 인프라 개요

# 1. 네트워크 기초

## OSI 7계층

|계층|역할|PDU|대표 장비/프로토콜|
|---|---|---|---|
|7 Application|사용자 서비스 제공|Data|HTTP, HTTPS, DNS|
|6 Presentation|암호화, 압축, 인코딩|Data|-|
|5 Session|세션 생성·유지·종료|Data|-|
|4 Transport|종단 간 통신|Segment|TCP, UDP, TLS|
|3 Network|IP 주소, 라우팅|Packet|IP, Router|
|2 Data Link|MAC 주소, 오류 검출|Frame|Ethernet, Switch|
|1 Physical|전기 신호 전송|Bit|Hub, NIC|

---

## TCP/IP 모델

- Application
- Transport
- Internet
- Network Access

OSI 7계층을 실제 인터넷에서 단순화한 모델이다.

---

# IP 주소

## IPv4

- 32bit
- 약 43억 개 주소
- 예) 192.168.0.1

### 공인 IP

- 인터넷에서 사용
- 전 세계 유일

### 사설 IP

- 내부 네트워크 전용
- 외부 접근 불가

---

## NAT

사설 IP ↔ 공인 IP 변환

- SNAT
- DNAT
- PAT

라우터나 NAT Gateway가 수행

---

## IPv6

- 128bit
- 주소 부족 해결
- 16진수 사용

---

# CIDR

클래스 대신

```
192.168.1.0/24
```

처럼 표현

/24 = 앞의 24비트가 네트워크 주소

---

# Port

프로세스를 구분하는 번호

예)

```
192.168.0.10:8080
```

IP → 컴퓨터

Port → 프로그램

---

# TCP vs UDP

## TCP

- 연결 지향
- 신뢰성 보장
- 순서 보장
- 흐름/오류/혼잡 제어

사용

- 웹
- 파일전송
- 이메일

---

## UDP

- 비연결
- 빠름
- 신뢰성 없음

사용

- 게임
- 스트리밍
- 영상통화

---

## TLS

보안 통신 제공

기능

- 기밀성
- 무결성
- 인증

HTTPS = HTTP + TLS

# AWS 글로벌 인프라

## Region

데이터센터가 모인 지역

예)

- 서울
- 도쿄

---

## AZ (Availability Zone)

리전 내부의 개별 데이터센터

특징

- 최소 3개 이상
- 장애 대비
- 고가용성

---

## Edge Location

사용자 가까운 캐시 서버

대표 서비스

- CloudFront
- Route53

---

# VPC

Virtual Private Cloud

AWS 안의 독립된 가상 네트워크

특징

- Region 단위
- 여러 VPC 생성 가능

---

# Subnet

VPC를 더 작은 네트워크로 분할

## Public Subnet

인터넷 연결 가능

## Private Subnet

인터넷 직접 연결 불가

---

# Internet Gateway

Public Subnet이 인터넷과 통신하도록 연결

---

# NAT Gateway

Private Subnet이 외부 인터넷으로 나갈 수 있게 함

(외부 → 내부 직접 접근은 불가)

---

## Network ACL

---

---

## IAM User

---

## Group

---

- Condition

```
   ▼

   │
   ▼
RDS (Database)

```

```
     │

     │
 Public Subnet
     │

     │
 NAT Gateway
     │
```

# 핵심 암기

- OSI 7계층과 TCP/IP 4계층 대응
- IPv4(32bit), IPv6(128bit)
- 공인 IP vs 사설 IP
- NAT의 역할
- TCP vs UDP 차이
- HTTPS = HTTP + TLS
- Region > AZ > Edge Location
- VPC → Subnet → EC2 구조
- Public Subnet은 Internet Gateway 필요
- Private Subnet은 NAT Gateway 필요
- Security Group(인스턴스, Stateful)
- Network ACL(서브넷, Stateless)
- IAM = 권한 관리
- EC2 = 가상 서버
- AMI = 서버 이미지
- S3 = 객체 스토리지
- RDS = 관리형 관계형 DB
- Multi-AZ = 장애 대비
- Read Replica = 읽기 성능 향상
