# 데이터베이스 개요

## 1. 데이터베이스 소개

### 데이터와 정보
- 데이터는 현실 세계에서 수집된 단순한 사실이나 값
- 정보는 데이터를 목적에 맞게 해석·가공한 결과
- 데이터 자체보다 이를 의미 있게 활용하는 과정이 중요함

### 데이터베이스(DB)
- 여러 사용자와 프로그램이 함께 사용하는 데이터를 통합 저장하는 공간
- 데이터를 효율적으로 관리하고 공유하기 위해 사용

### 파일 처리 시스템의 한계
- 데이터 구조가 바뀌면 프로그램도 수정해야 하는 데이터 종속 문제 발생
- 프로그램마다 데이터를 따로 관리하면 중복 데이터 발생
- 데이터 중복으로 인해 무결성이 깨질 수 있음

### 무결성(Integrity)
- 데이터가 정확하고 일관된 상태로 유지되는 성질
- 잘못된 값이나 충돌 없이 안정적으로 관리되어야 함

### 데이터베이스의 특징
- 실시간 접근성
  - 필요한 순간 바로 데이터 접근 가능
- 지속적인 변화
  - 삽입, 수정, 삭제를 통해 최신 상태 유지
- 동시 공유
  - 여러 사용자가 동시에 사용 가능
- 내용 기반 참조
  - 저장 위치가 아니라 값 자체로 검색 가능

## 2. 데이터베이스 종류

### RDB(Relational Database)
- 행(Row)과 열(Column) 형태의 테이블 기반 구조
- 관계 모델을 사용해 데이터를 관리
- 스키마가 정해져 있어 데이터 안정성과 무결성이 높음
- 데이터 구조가 일정한 경우 적합

#### 대표적인 RDBMS
- MySQL
- PostgreSQL
- MariaDB

### NoSQL
- 고정된 스키마 없이 유연하게 데이터 저장 가능
- 데이터 형태가 자주 바뀌는 환경에 적합
- 대용량 데이터를 빠르게 처리 가능

#### 대표적인 NoSQL DB
- MongoDB
- Redis
- Apache Cassandra

### RDB vs NoSQL 비교
| RDB | NoSQL |
|---|---|
| 테이블 기반 구조 | 자유로운 데이터 구조 |
| 무결성과 안정성 중요 | 확장성과 처리 속도 중요 |
| 정형 데이터에 적합 | 비정형·대용량 데이터에 적합 |
| 스키마 고정 | 스키마 유연 |

## 3. 관계형 데이터베이스 만들기

### 관계형 데이터베이스 구성 요소
- 테이블(Table)
  - 데이터를 저장하는 기본 단위
- 행(Row, Tuple)
  - 하나의 데이터 레코드
- 열(Column, Attribute)
  - 데이터의 속성
- 도메인(Domain)
  - 속성이 가질 수 있는 값의 범위

### 관계(Relation)
- 공통 속성을 이용해 여러 테이블 연결 가능
- 데이터 중복을 줄이고 효율적으로 관리 가능

CREATE TABLE customer(
