# SQL 시작하기

## SQL과 데이터베이스

### 데이터베이스
- 여러 사용자가 공유하여 사용할 목적으로 데이터를 통합 관리하는 시스템
- MariaDB, Oracle DB, Amazon Redshift 등 다양한 종류가 존재
- 데이터베이스마다 세부 사용법은 다르지만 기본적인 데이터 검색과 분석 방식은 유사함

### SQL
- Structured Query Language의 약자
- 데이터베이스에 접근하고 데이터를 조작하기 위한 표준 언어
- 관계형 데이터베이스를 제어하는 데 사용

### SQL로 할 수 있는 일
- 데이터 검색(SELECT)
- 데이터 삽입(INSERT)
- 데이터 수정(UPDATE)
- 데이터 삭제(DELETE)
- 데이터베이스 생성
- 테이블 생성

### SQL 문장 구조
```sql
DESC Employees;
```

- DESC : 실행할 명령어
- Employees : 명령 대상

## 관계형 데이터베이스와 테이블

### 데이터베이스 종류
- 관계형 데이터베이스(RDBMS)
- 비관계형 데이터베이스(NoSQL)

### 관계형 데이터베이스
- 하나 이상의 테이블로 구성
- 테이블 간 관계를 통해 데이터를 연결
- SQL을 이용해 데이터를 관리

### 테이블 구조
- Column(컬럼) : 데이터의 속성
- Record(Row, 레코드) : 실제 데이터 한 행

| 사번 | 이름 | 성별 |
|------|------|------|
| 001 | 홍길동 | 남성 |
| 002 | 김철수 | 남성 |
| 003 | 김영희 | 여성 |

- 사번, 이름, 성별 → 컬럼
- 각 행의 데이터 → 레코드
- 모든 테이블은 고유한 이름을 가짐

## SELECT로 데이터 조회하기

### 특정 컬럼 조회

```sql
SELECT title, author
FROM book;
```

- book 테이블의 title, author 컬럼 조회

### 모든 컬럼 조회

```sql
SELECT *
FROM book;
```

- `*` : 모든 컬럼 조회

### DISTINCT
- 중복 데이터를 제거하여 조회

```sql
SELECT DISTINCT title
FROM book;
```

### DISTINCT 사용 시 주의점

```sql
SELECT DISTINCT title, author
FROM book;
```

- 여러 컬럼을 함께 사용하면 모든 컬럼 조합이 동일해야 중복으로 처리
- 한 컬럼만 같고 다른 컬럼이 다르면 서로 다른 데이터로 조회

## WHERE로 조건 검색하기

### WHERE
- 원하는 조건에 맞는 데이터만 검색

```sql
SELECT *
FROM book
WHERE title = '돈키호테';
```

- 제목이 '돈키호테'인 데이터 조회

### 비교 연산자

| 연산자 | 의미 |
|---------|---------|
| > | 초과 |
| < | 미만 |
| >= | 이상 |
| <= | 이하 |
| = | 같다 |
| != | 같지 않다 |

### 예제

```sql
SELECT *
FROM score
WHERE korean >= 90;
```

- 국어 점수가 90점 이상인 데이터 조회

---

## 여러 조건 사용하기

### AND
- 모든 조건을 만족하는 데이터 조회

```sql
SELECT *
FROM score
WHERE korean >= 90 AND math > 80;
```

### OR
- 하나 이상의 조건을 만족하는 데이터 조회

```sql
SELECT *
FROM score
WHERE korean >= 90 OR math > 80;
```

### NOT
- 조건을 만족하지 않는 데이터 조회

```sql
SELECT *
FROM score
WHERE NOT korean >= 90;
```

### 복합조건 연산자

| 연산자 | 의미 |
|---------|---------|
| AND, && | 두 조건 모두 만족 |
| OR, \|\| | 둘 중 하나 이상 만족 |
| NOT, ! | 조건 부정 |

## 범위 및 집합 조건 검색

### BETWEEN
- 특정 범위의 값을 조회
- 시작값과 끝값 포함

```sql
SELECT *
FROM score
WHERE math BETWEEN 80 AND 90;
```

- 수학 점수가 80 이상 90 이하인 데이터 조회

### IN
- 여러 값 중 하나와 일치하는 데이터 조회

```sql
SELECT *
FROM book
WHERE publisher IN ('엘리스 출판', '한빛미디어');
```

### NOT IN
- 특정 값 목록에 포함되지 않는 데이터 조회

```sql
SELECT *
FROM book
WHERE publisher NOT IN ('엘리스 출판');
```

## 핵심 정리

- SQL은 데이터베이스를 조작하기 위한 표준 언어이다.
- 관계형 데이터베이스는 테이블과 관계를 통해 데이터를 관리한다.
- SELECT로 데이터를 조회한다.
- DISTINCT로 중복 데이터를 제거할 수 있다.
- WHERE로 원하는 조건의 데이터를 검색한다.
- 비교 연산자와 AND, OR, NOT을 조합해 조건 검색을 수행한다.
- BETWEEN, IN, NOT IN을 이용해 범위 및 집합 조건 검색을 수행할 수 있다.
