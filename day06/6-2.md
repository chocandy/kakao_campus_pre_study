# 데이터를 제어하는 DML (데이터 조작어)

## DML(Data Manipulation Language)

- 데이터베이스에 저장된 데이터를 조회, 추가, 수정, 삭제하는 명령어 집합
- 데이터를 직접 다루는 작업에 사용
- 주요 명령어 : SELECT, INSERT, UPDATE, DELETE

---

## LIKE를 이용한 유사 데이터 검색

### LIKE
- 문자열의 일부만 알고 있을 때 사용하는 검색 조건
- 특정 문자 포함 여부, 시작 문자, 끝 문자 등을 기준으로 검색 가능

### 정확히 일치하는 값 검색

```sql
SELECT *
FROM book
WHERE title LIKE '어린왕자';
```

### 특정 문자열로 끝나는 데이터 검색

```sql
SELECT *
FROM book
WHERE title LIKE '%왕자';
```

- `%` : 앞에 어떤 문자열이 와도 허용

### 특정 문자열로 시작하는 데이터 검색

```sql
SELECT *
FROM book
WHERE title LIKE '어린%';
```

- 뒤에 어떤 문자열이 와도 허용

### 특정 문자열을 포함하는 데이터 검색

```sql
SELECT *
FROM book
WHERE title LIKE '%린왕%';
```

- 문자열 중간에 해당 단어가 포함된 데이터 검색

## 데이터 정렬하기

### ORDER BY
- 조회 결과를 원하는 기준으로 정렬
- 성적, 가격, 날짜 등 크기 비교가 가능한 데이터 정렬 시 사용

### 내림차순 정렬 (큰 값 → 작은 값)

```sql
SELECT *
FROM score
ORDER BY math DESC;
```

- 수학 점수가 높은 순으로 정렬

### 오름차순 정렬 (작은 값 → 큰 값)

```sql
SELECT *
FROM score
ORDER BY math ASC;
```

- 수학 점수가 낮은 순으로 정렬

### 정렬 키워드

| 키워드 | 의미 |
|----------|----------|
| ASC | 오름차순 |
| DESC | 내림차순 |

> DESC는 정렬 옵션이며, `DESC 테이블명` 명령과는 다른 의미

## 데이터 삽입하기

### INSERT
- 테이블에 새로운 데이터를 추가

### 기본 문법

```sql
INSERT INTO book(id, title, author, publisher)
VALUES('3', '햄릿', '윌리엄 셰익스피어', '엘리스 출판');
```

### 구성 요소

- INSERT INTO : 데이터를 추가할 테이블 지정
- VALUES : 저장할 데이터 입력

### 컬럼 생략 가능

```sql
INSERT INTO book
VALUES('3', '햄릿', '윌리엄 셰익스피어', '엘리스 출판');
```

- 컬럼을 생략하면 테이블 정의 순서대로 값이 입력됨
- 순서를 정확히 알아야 하므로 컬럼을 명시하는 것이 안전

---

## 데이터 수정하기

### UPDATE
- 이미 저장된 데이터를 변경

### 기본 문법

```sql
UPDATE book
SET title = '돈키호테 1'
WHERE title = '돈키호테';
```

### 구성 요소

- UPDATE : 수정할 테이블 지정
- SET : 변경할 컬럼과 값 지정
- WHERE : 수정 대상 지정

### 주의점

```sql
UPDATE book
SET title = '돈키호테 1';
```

- WHERE가 없으면 모든 행이 수정됨

---

## 데이터 삭제하기

### DELETE
- 테이블에 저장된 데이터를 삭제

### 기본 문법

```sql
DELETE
FROM book
WHERE title = '돈키호테 1';
```

### 구성 요소

- DELETE FROM : 데이터를 삭제할 테이블 지정
- WHERE : 삭제 대상 지정

### 주의점

```sql
DELETE
FROM book;
```

- WHERE가 없으면 테이블의 모든 데이터가 삭제됨
- 실무에서는 DELETE 실행 전 WHERE 조건을 반드시 확인

---

## 핵심 정리

- LIKE는 문자열 패턴 검색에 사용한다.
- `%`를 이용해 시작, 끝, 포함 조건 검색이 가능하다.
- ORDER BY로 조회 결과를 정렬할 수 있다.
- ASC는 오름차순, DESC는 내림차순이다.
- INSERT는 새로운 데이터를 추가한다.
- UPDATE는 기존 데이터를 수정한다.
- DELETE는 데이터를 삭제한다.
- UPDATE와 DELETE는 WHERE 조건을 빠뜨리지 않도록 주의해야 한다.
