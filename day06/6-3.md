# SQL과 함수

## SQL 함수

- SQL은 데이터를 조회하는 것뿐만 아니라 다양한 계산을 수행하는 함수도 제공한다.
- 함수는 조회 결과를 집계하거나 필요한 통계 정보를 얻을 때 사용한다.
- 대표적인 집계 함수로 COUNT, SUM, AVG, MAX, MIN이 있다.

---

## COUNT

### COUNT
- 조회된 데이터의 개수를 반환하는 함수
- NULL 값은 개수에서 제외

### 특정 컬럼 개수 조회

```sql
SELECT COUNT(id)
FROM book;
```

- id 컬럼에 값이 존재하는 행의 개수 조회

### 전체 데이터 개수 조회

```sql
SELECT COUNT(*)
FROM book;
```

- 테이블의 전체 행 개수 조회

### 활용 예시
- 등록된 회원 수 확인
- 보유 도서 수 확인
- 주문 건수 확인

---

## LIMIT

### LIMIT
- 조회 결과의 개수를 제한하는 명령어
- 많은 데이터 중 일부만 확인할 때 사용

### 상위 5개 데이터 조회

```sql
SELECT *
FROM book
LIMIT 5;
```

### 두 번째 데이터부터 5개 조회

```sql
SELECT *
FROM book
LIMIT 1, 5;
```

- LIMIT 시작위치, 개수
- 시작 위치는 0부터 계산
- LIMIT 1, 5는 두 번째 데이터부터 5개 조회

### 활용 예시
- 게시판 최신 글 조회
- 상위 10개 결과 출력
- 페이지네이션 구현

---

## SUM

### SUM
- 지정한 컬럼 값의 총합을 계산하는 함수
- 숫자형 데이터에 사용

### 기본 문법

```sql
SELECT SUM(math)
FROM grade;
```

- math 컬럼의 전체 합계 계산

### 활용 예시
- 총 매출 계산
- 과목 총점 계산
- 판매 수량 합계 계산

---

## AVG

### AVG
- 지정한 컬럼의 평균값을 계산하는 함수

### 기본 문법

```sql
SELECT AVG(korean),
       AVG(english),
       AVG(math)
FROM grade;
```

- 국어, 영어, 수학 평균 점수 계산

### 특징
- SUM과 COUNT를 직접 계산하지 않아도 평균을 구할 수 있음
- NULL 값은 평균 계산에서 제외

### 활용 예시
- 평균 성적 계산
- 평균 매출 계산
- 평균 이용 시간 계산

---

## MAX

### MAX
- 컬럼에서 가장 큰 값을 반환하는 함수
- 숫자형뿐 아니라 문자형 데이터에도 사용 가능

### 기본 문법

```sql
SELECT MAX(korean)
FROM grade;
```

- 국어 점수 최고점 조회

### 활용 예시
- 최고 점수 조회
- 최대 매출 조회
- 가장 최근 날짜 조회

---

## MIN

### MIN
- 컬럼에서 가장 작은 값을 반환하는 함수
- 숫자형뿐 아니라 문자형 데이터에도 사용 가능

### 기본 문법

```sql
SELECT MIN(english)
FROM grade;
```

- 영어 점수 최저점 조회

### 활용 예시
- 최저 점수 조회
- 최소 가격 조회
- 가장 오래된 날짜 조회

---

## 집계 함수 정리

| 함수 | 기능 |
|--------|--------|
| COUNT() | 데이터 개수 |
| SUM() | 총합 |
| AVG() | 평균 |
| MAX() | 최댓값 |
| MIN() | 최솟값 |

---

## 핵심 정리

- COUNT는 데이터 개수를 구한다.
- LIMIT는 조회 결과 개수를 제한한다.
- SUM은 값들의 합계를 구한다.
- AVG는 평균값을 구한다.
- MAX는 최댓값을 구한다.
- MIN은 최솟값을 구한다.
- 집계 함수는 데이터 분석 및 통계 처리에 자주 사용된다.
- COUNT, SUM, AVG, MAX, MIN은 대표적인 SQL 집계 함수이다.
